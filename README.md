# plain-reads

技术文章的解读版。原文一字不改，每个逻辑段落后面加一个虚线注释框，依次是：这段在说什么、术语、翻译、例子。目标是从头到尾读一遍就能看懂，不用另外查资料。

每个文件都是单个 HTML，下载后用浏览器直接打开即可。

## 许可

每篇解读版沿用原文的许可，署名、原文链接和改动说明写在页面页脚。新增的中文注释、翻译、总结和术语表按同一许可共享。
